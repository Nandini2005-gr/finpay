# 💳 FinPay — Personal Finance Dashboard

A full-stack fintech web app to track expenses, manage wallet, and get spending insights.

## 🚀 Features
- JWT Authentication (Register/Login)
- Real-time wallet balance tracking
- Add income & expense transactions
- Interactive charts (Area + Pie)
- Spending by category analytics
- Responsive dark UI

## 🧱 Tech Stack
| Layer | Tech |
|---|---|
| Frontend | React + Tailwind CSS + Recharts |
| Backend | Python FastAPI |
| Database | PostgreSQL + SQLAlchemy |
| Auth | JWT Tokens |

## 📦 Setup

### Backend
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
